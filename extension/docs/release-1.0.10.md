# 公考内容排版 1.0.10 · 纸上作答用时隔离

- 导入粉笔报告时可勾选「纸上作答／仅补录答案」。平台记录的录入用时保留，但不参与整卷、模块、题型和单题速度统计。
- 可填写实际纸上作答总用时（整数秒）；未知留空，显示「—」。实际总用时只用于整卷，不平均分配到题目或模块。
- 正确率、题量、错题及平台统计正常保留。再次导入仍只补缺失统计，不覆盖已有计时选择或练习日期。
- 已导入的历史记录可在新版小程序编辑计时选择、实际日期及各级实际用时；本轮仅更新小程序源码，未发布微信版本。
- 配套后端同时修复导出的小箭头、根号及多图片／混合文字选项；原题无需重新导入，旧 PDF / Word 需重新导出才会生效。

## 安装

解压生产 ZIP，在浏览器扩展管理页面加载含 `manifest.json` 的目录；已有插件重新加载并确认 **1.0.10**，再刷新粉笔页面。不要同时启用两份插件。

生产 API：`https://api.yzxj.vip`。这是开发者模式 ZIP，不是签名 CRX，未发布浏览器商店。真实账号导入与打印仍需用户实测。
