# 公考内容排版 1.0.8 · 粉笔统计快照与构建依赖修复

## 本次更新

- 后续新导入粉笔报告可携带真实逐题平台正确率、原始计数和整卷平均分、击败率、原平台难度等统计快照，支持小程序中的相对平台参照趋势。
- 统计仅从原站已加载响应被动捕获；通过报告请求标识精确匹配题目，不主动向粉笔重复请求。缺失统计保持未知，真实零保留为0。
- 读取报告时展示逐题正确率覆盖数量。未齐全时可先在粉笔打开完整解析，再重新读取，确认覆盖后导入。
- 配套后端仅为后续新报告保存统计，首次归档后冻结；旧报告重导不回填、原题缺失统计不补写。旧记录不迁移。
- 修复插件依赖指向主仓失效共享目录而无法构建的问题。插件自身依赖和锁文件位于 `extension`，不借用小程序依赖；生产构建仍包含 TypeScript 检查。
- 保留1.0.7的每次错误记录、历史用时关联，以及既有排版、扫码、反馈和下载功能。

## 更新安装与导入

1. 完整解压ZIP到固定目录，选择含 `manifest.json` 的目录。首次安装在Chrome/Edge扩展管理页开启开发者模式，选择“加载已解压的扩展程序”。这是开发者模式ZIP，不是签名CRX。
2. 更新时替换原扩展目录并点击“重新加载”，避免同时启用两份插件。确认显示版本 **1.0.8**。
3. **F5刷新已打开的粉笔网页**，打开要导入的新报告及完整解析，点击插件读取报告。
4. 预览中核对“平台逐题正确率”覆盖数量、题目明细和日期，然后导入。示例130题报告应在数据齐全时显示130/130；不能用示例值代替原站统计。
5. 在小程序“练习数据 → 导入/手动记录”中查看难度参照趋势。单份报告仍会提示趋势证据不足；这不是导入失败。

## 配套服务前置条件（重要）

**插件包构建成功不等于生产数据链路已经上线。当前生产 API 为 `https://api.yzxj.vip`，必须部署支持新统计字段的后端，才能可靠归档统计。**

- 配套主仓功能提交为 `f6549c1c`，后端需包含统计Schema、导入冻结策略及 `GET /api/v1/gk/practice-logs/reference-trends`。仅部署旧后端可能忽略新字段，不能视为统计已经保存。
- 小程序功能提交为 `d8f311b`，应使用包含参照面板的版本才能查看新趋势。
- 统计功能自身复用现有JSON，无新增DDL；这不代表其他尚未执行的错题趋势迁移可以自动跳过或自动上线。
- 本次没有部署后端、写生产数据库、上传小程序或发布浏览器商店。未在真实账号下执行生产导入；生产联调需在配套服务上线后单独进行。
- 不把平台正确率当成已经校准的绝对能力，不把抓取时统计解释为作答当日统计。数据不足时不作进步判断。

## 本地可复现构建

在 `extension` 目录执行：

```powershell
pnpm run deps:install
pnpm run build:prod
```

依赖安装只作用于插件，使用本地锁文件；不会安装整个父级workspace，也不执行依赖生命周期脚本。已有构建成功且代码未改动时，不重跑构建；直接用 `scripts/package.ps1 -Destination <新目录>` 打包。默认打包命令包含再次构建，按项目验证复用规则谨慎使用。
