# 公考内容排版 1.0.9 · 导入自动识别重导，仅补统计

## 更新内容

- 不新增模式或按钮。点击原有“确认导入”，后端按账号、平台和报告编号自动识别是否已导入。
- 新报告正常归档；已有报告只补缺失的平台整卷、逐题统计。已有值不覆盖，真实0保留。
- 不改练习日期、答案、对错、用时、题目内容、解析或题型，不新增重复练习记录。
- 逐题不能精确匹配原题时跳过，成功提示显示补充项数、更新题数、跳过题数和原因。
- 补到的是本次页面捕获的统计，不是作答当日统计；字段记录自己的实际抓取时间。历史趋势始终使用首次统计，旧报告不会自动进入趋势。
- 仅汇总旧记录可以保存整卷统计，但不能用重导补造缺失题目或作答。

## 安装与测试

1. 解压ZIP，加载含`manifest.json`的目录；已有插件更新后点“重新加载”，确认版本 **1.0.9**，不要同时启用两份。
2. **F5刷新粉笔网页**，打开原报告及完整解析，核对预览中的逐题统计覆盖数量。
3. 使用原有导入按钮：新报告会正常归档；旧报告会显示仅补统计结果，再点一次不会覆盖或重复新增。
4. 遇到题目版本、模块路径或答案不一致，查看跳过提示，不用改历史答案来强行匹配。

配套生产API为`https://api.yzxj.vip`，须部署支持`reference_supplement`的后端；旧`3a96bf57`只有新报告统计，不具备自动补统计规则。上线版本以本次部署记录为准。

这是开发者模式ZIP，不是签名CRX；未发布浏览器商店。小程序新增参照面板尚未上传，旧线上小程序不会出现该面板。真实账号端到端验收由用户实测，不以本地测试或构建冒充。

本地构建仍使用插件独立依赖：`pnpm run build:prod`。同一产物通过后不再构建，直接执行`scripts/package.ps1 -Destination <新目录>`打包，不覆盖旧1.0.8包。
