# 公考内容排版 1.0.4 · 生产安装包

## 本次更新

- 统一“导入错题”和“导入记录”的题干、选项、图片、行内符号及多选答案清洗规则，保留原站稳定题号，避免两入口将同题识别为不同题。
- 保护 `Answer`、`AB`、`A+B`、`A + B` 等真实选项内容，缺失用时与真实零秒分别保留。
- 配套后端统一题目复用及历史同题校验逻辑，兼容旧题关联，不物理合并或删除历史数据。
- 延续生产 HTTPS API、真实扫码、额度、下载失败分册重试、离线帮助与意见反馈能力；不加入模拟成功或本地官网桥接。

## 归档规则

- **同一次练习**按“账号 + 平台 + 练习报告编号”去重。无论先导错题还是先导完整记录，都不会因此生成第二份整卷归档。
- **同一张卷第二次作答**应有新的练习报告编号；再次导入会新建一份练习记录，保留两次作答及各自用时，共用可复用的题目内容。
- 仅导入错题不会自动生成整卷；导入练习记录也不会自动将其中所有错误题加入错题本。
- 答案和用时来自同一次真实作答。原站没有提供用时则显示未知，不按总时长均摊，也不借用另一次作答的用时。

详细语义见包内《错题与练习归档说明.md》。

## 安装或更新（Chrome / Edge）

1. 将 ZIP 完整解压到固定目录，不要直接在压缩软件中运行。
2. 进入 `chrome://extensions/` 或 `edge://extensions/`，打开开发者模式。
3. 首次安装点击“加载已解压的扩展程序”，选择含 `manifest.json` 的解压目录。
4. 已安装旧版本时，将文件更新到原扩展目录后点击“重新加载”，避免同时启用两个版本；不要删除浏览器使用的安装目录。
5. 确认版本为 1.0.4，刷新已打开的题库网页后再操作。

这是开发者模式 ZIP 安装包，不是商店签名 CRX。

## 必须注意：ZIP 不会更新服务器

本次只构建和打包插件，**不部署后端、不发布小程序**。

错题与记录的可靠复用、历史同题读取、缺失用时补全及归档逻辑还依赖本轮配套后端。仅替换插件，不能让旧后端具备这些行为。
