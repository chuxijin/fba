# 公考内容排版 1.0.3 · 生产安装包

## 本次交付范围

- 生产 API 固定为 `https://api.yzxj.vip`，不是本地联调包。
- 不展示未提供正式地址的官网入口；生产权限移除 localhost 和本地官网注入。
- 内置离线帮助页；意见反馈提交到现有 `/api/v1/feedbacks`，登录后通过 `/api/v1/feedbacks/mine` 查看回复。匿名反馈不能关联账号记录。
- 去掉模拟扫码、测试账号填充、写死15次额度、未支持题库的“适配中”展示及假进度百分比。
- 登录二维码严格只接受微信 PNG/JPEG；错误明确提示并允许重新获取，支持账号密码登录。
- 复用现有渲染文件，电脑自动逐册下载，失败只重试失败分册；真实题本领取码扫码进入“我的题本”，不授权电脑登录、不下单。
- 弹窗、悬浮窗、反馈页版本均取自 manifest，统一为 1.0.3。

## 安装（Chrome / Edge）

1. 将 ZIP 解压到一个固定目录，保留全部文件。不要在压缩软件中直接打开。
2. 进入 `chrome://extensions/` 或 `edge://extensions/`，打开开发者模式。
3. 点击“加载已解压的扩展程序”，选择含 `manifest.json` 的解压目录。
4. 如果已安装旧版本，优先在原扩展目录替换文件并点击“重新加载”；使用其他目录可能产生第二个扩展实例，请避免两个版本同时运行。
5. 刷新已打开的题库网页，再点击扩展图标或页面“开始排版”。

ZIP 是开发者模式安装包，不是 Chrome 商店签名 CRX。请不要删除安装目录，否则浏览器无法继续加载。

## 重要：后端／小程序前置条件

本次按要求只构建和打包，不部署后端、不上传或发布小程序。ZIP 不会更新服务器。

2026-11-01 只读检查生产地址发现：

| 检查项 | 当前结果 | 含义 |
| --- | --- | --- |
| `GET /api/v1/render-books/public/quota` | 200 | 额度接口可访问 |
| `GET /api/v1/render-books/public/exports` | 404 | 新排版路由未发布；若已发布仅 POST 路由，GET 应是405 |
| `GET /api/v1/render-books/public/reformat` | 405 / Allow: POST | 仍有旧同步排版接口 |
| 无效 token 的 `GET /api/v1/render-books/public/minicode/...` | 200 / image/svg+xml | 仍是旧占位码实现，不是本轮真实领取码接口 |
| `GET /api/v1/feedbacks/mine`（未登录） | 401 | 反馈记录受登录保护，符合预期 |

因此当前生产服务不能完成本轮新排版／扫码题本闭环。插件遇到旧服务会明确报错，不伪造成功，也不会回退调用旧排版重复扣额度。**不要把安装包构建完成等同于线上完整验收通过。**

上线前需发布本轮 `render_book` 交付接口及 `oauth2` 登录码修复，并更新小程序：

- `pages/mine/index` 接收 `fba_` 登录 scene 并向 `/oauth2/wechat/scan/confirm` 确认。
- `pkg/mine/render-books/index` 接收 `rb_` 领取 scene，登录回跳保留凭证，允许保存和打开主册／答案册。
- 正式微信 AppID／Secret 由服务端安全配置，不放进 ZIP；微信主体权限、正式页面路径及 request/downloadFile 合法域名需正确配置。
- 多后端实例需要共享 `RENDER_BOOK_STORAGE_ROOT`；进程内 BackgroundTasks 不支持服务重启续跑。
