# ⚠️ 图标占位说明

## 当前状态

此目录需要放置 **8 个 TabBar 图标文件**，用于底部导航栏显示。

## 所需文件

```
static/tabbar/
├── home.png              (81×81px, #6b7280)  - 首页（未选中）
├── home-active.png       (81×81px, #22c55e)  - 首页（选中）
├── practice.png          (81×81px, #6b7280)  - 练习（未选中）
├── practice-active.png   (81×81px, #22c55e)  - 练习（选中）
├── study.png             (81×81px, #6b7280)  - 学习（未选中）
├── study-active.png      (81×81px, #22c55e)  - 学习（选中）
├── mine.png              (81×81px, #6b7280)  - 我的（未选中）
└── mine-active.png       (81×81px, #22c55e)  - 我的（选中）
```

## 快速获取

查看同级目录的 `README.md` 文件��里面有详细的图标准备指南和资源链接。

## 临时方案

在没有正式图标前，可以：
1. 使用占位图（参考 README.md 中的链接）
2. 或者暂时注释掉 `pages.json` 中 tabBar 的 iconPath 配置

```json
// 临时方案：注释掉图标路径
{
  "pagePath": "pages/index/index",
  "text": "首页"
  // "iconPath": "static/tabbar/home.png",
  // "selectedIconPath": "static/tabbar/home-active.png"
}
```

这样 TabBar 会以纯文字形式显示，等图标准备好后再取消注释。
