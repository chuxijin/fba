# 计算练习出题规则（generator_version 1.1.0）

## 本轮实现

- 不引入 SDK 或通用规则引擎，复用现有 calculation 服务。
- 共用数量生成器在调用方允许的区间内先抽位数、再抽整数，通常覆盖三到五位数；不强制整十、整百或特征分母的倍数。各题型仍保留各自合理的范围，年份、人数、截位训练等不套统一位数。
- 数值选择题的最近干扰项：简单 15%～20%，普通 9%～11%，困难 4.5%～5.5%。按显示精度取整，允许半个显示单位的量化误差；零和极小答案至少相隔一个显示单位。范围选择与大小比较不使用这条数值规则。
- 填空相对容差统一 5%，不跟随难度变化。专项填空返回未取整数学答案；进阶填空使用题干数学真值判题，避免旧的绝对误差兜底覆盖规则。零只能答零；比较题、选项与截位前两位题精确判定。基础四则运算不改为近似判题。
- 特征分数围绕真实 100/n 扰动并避开其直接显示值，校验增长量/下降量近似误差。进阶文字选择题还检验近似结果唯一最接近正确选项，因此不会强行接受所有扰动（例如 15.6% 不一定能直接当 1/7 使用）。
- 假设分配生成现期、增长率与易算假设基期。余差 R = 现期 - 假设基期×(1+r)，基期近似为 假设基期 + R×(1-r)。同时验证基期与最终增长量的误差不超过 1%，给困难选项间距留出余量。
- `growth_amount + hard + allocation` 已直接接入此约束。指定 allocation / char_fraction 的随机实战题单只混合基期量和增长量，避免随机选到完全无关题型。
- 普通文字题不提示内部目标数或假设值；已有公式专项模式保留必要提示与中间步骤。接口说明和历史记录中的 explanation 字段为兼容保留，未删除现有解析界面。

## 接口兼容与边界

原有接口、字段命名和题型不变；advanced 请求新增可选 `difficulty`，缺省 normal。旧小程序请求无需更改即可工作，尚未添加新的进阶难度选择控件。

示例：向 `/api/v1/gk/calculation-practice/data-practice/generate` 提交：

```json
{"type_key":"growth_amount","difficulty":"hard","method_bias":"allocation","count":10,"seed":72}
```

`method_bias` 仍是兼容旧接口的数字结构偏向，不表示所有复合题型都已实现指定速算方法的严格适用性认证。本轮严格校验的重点是基期/增长量与特征分数、假设分配，以及进阶特征分数选择题。对其他指定题型保留原有支持行为，不自动改题型、不拒绝旧请求；若后续要开放任意算法与任意方法的组合，需要逐项扩展适用性规则。

填空没有选项，因此不以选项差距表达其难度；原有分数分母范围、年数等结构难度保留。升级闯关调用现有出题接口可复用本轮规则，未新增自动插题或学习计划编排功能。

版本已更新，相同版本、参数与 seed 可复现；旧版本 seed 不保证产生相同题单。

## 真机验收

1. 本轮只修改本地代码，没有部署服务器。先确保手机使用的后端已运行新代码，再重新编译小程序；生成响应版本应为 1.1.0。
2. 专项实战分别选简单、普通、困难，各做一组，观察最近选项由宽到窄。
3. 填空输入真值的 95% 和 105% 应判对，超出边界应判错；负数规则相同，零不能用小非零数蒙对。
4. 进阶特征分数观察百分数有扰动、数量不刻意整除；按现期/(n+1) 估算应能选择正确项。
5. 假设分配同时检查基期和增长量；乘法放缩的百分数输入按相对 5% 判定，不再按固定 0.05 个百分点判定。
6. 比较、范围估算、历史记录与末题结算再各走一遍。

自动回归是隔离的出题/接口与客户端测试，不等同于真实后端启动、数据库连接、手机网络或线上部署验收。
