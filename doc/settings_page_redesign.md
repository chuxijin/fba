# 设置页整理（2026-10-10）

## 范围

仅调整小程序设置页及本地验证，不改后端接口、数据库、依赖或发布状态。

- 页面：`mini/src/pkg/mine/settings/index.vue`
- 回归：`mini/tests/settings-page.test.cjs`
- 浏览器模拟验证：`mini/scratch/settings-preview.cjs`

## 页面与交互

1. 按「练习偏好 / 通用 / 隐私与协议」分组，重置数据单独放在最底部。
2. 复用 Wot Cell、CellGroup、Popup，通过现有全局语义变量统一浅灰绿背景、实色卡片、文字、分割线与选中状态。去掉紫粉光斑与半透明背景。
3. 常规列表默认约 54px 行高；清理和关闭按钮至少 44px。法律条目分配更宽标题区，避免窄屏下无意义换行。
4. 「我的题本」仅移除设置页重复入口，用户中心学习资产入口保留。
5. 「随机练习范围」改成「随机练习年份」；「错题掌握连对次数」改成「错题掌握标准」；「题目夜间模式」改成「外观模式」。接口值与可选项不变。
6. 五类设置共用一个底部选择面板。当前值显示绿色底色和勾选，规则说明放在对应面板。关闭或点选原值不提交，点选新值沿用原有保存逻辑。
7. 缓存容量与清理操作合并一行。无缓存时显示「暂无缓存」并禁用清理。清理使用普通主题色，说明不影响答题记录。
8. 重置保留不可恢复说明及两次确认，整个确认流程防重复点击，确认期间账户变更或页面卸载时不发起重置。
9. 新的本地选择会使正在进行的初始偏好读取失效，避免慢响应覆盖用户操作；保留原有会话校验及保存失败处理。

## 真机建议

1. 重新编译，进入「我的 → 设置」，检查间距、标题对齐和底部安全区。
2. 分别修改练习题数、年份、模式、掌握标准；退出重进确认当前值。
3. 切换浅色 / 深色 / 跟随系统，检查页面及选择面板；关闭面板不应改变设置。
4. 检查缓存为空时不可清理；有缓存时确认文案，必要时清理本机图片视频缓存。
5. 重置只需检查两次确认与取消，不要为了视觉验收清空真实学习记录。
