## 数据口径与边界

1. 累计字段仍使用现有累计报告，不拿近30天或近12月替代。
2. 作答量是提交次数，不是去重后的题目数；界面使用“次”。
3. 正确率使用答对次数 / 已判题次数。没有已判题数据显示 `—`；真实全部答错显示 `0%`。
4. 接口的每日趋势补齐到服务端当天，以末尾日期作为报告日期，避免客户端跨时区错位。
5. 一个 `days=365` 请求供应全部区域，切换视图不重复请求。
6. 近12月只显示当前月及之前11个自然月，不误展示13个月。接口最多提供365天；遇到首月不完整的闰年边界会提示起始日，本月说明截至报告日期。
7. 空记录不显示“峰值0”；缺失趋势与已返回的全零趋势分别处理。
8. 刷新中保留旧数据，失败显示提示并可重试；账号改变即清除缓存，旧请求不得回填；页面卸载后忽略结果。
