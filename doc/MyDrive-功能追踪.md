# MyDrive 功能追踪

更新时间：2026-07-14

## 使用范围

MyDrive 是新的内部网盘文件空间模块。它独立于 `coulddrive`，按账户、个人空间和外部分享空间组织文件能力。

当前支持的 Provider：百度网盘、夸克网盘、迅雷网盘。

## 已完成

### 账户与空间

- [x] 网盘账户 CRUD。
- [x] 百度、夸克、迅雷账户资料同步。
- [x] 个人空间与百度、夸克分享链接空间创建。
- [x] 子目录挂载，客户端路径以挂载根目录为 `/`。
- [x] 账户所有权、Provider 一致性和远端可访问性预检。

### 文件浏览与操作

- [x] OpenList 风格目录列表：路径、分页、强制刷新。
- [x] 虚拟路径隔离，拒绝 `.`、`..` 路径穿越。
- [x] 创建目录、复制、移动、重命名、删除。
- [x] 文件写操作在服务端重新解析远端文件，不信任客户端传入的名称、路径、父目录或扩展信息。
- [x] 目录 Redis 缓存、TTL、精确目录/子树失效、回源锁防止缓存击穿。

### 外部转存

- [x] API：`POST /api/v1/mydrive/spaces/{source_space_id}/transfer`。
- [x] 百度分享链接空间浏览和转存到百度个人空间。
- [x] 夸克分享链接空间浏览和转存到夸克个人空间。
- [x] 百度加密分享会话自动初始化：仅使用账户 Cookie、分享链接和提取码，临时会话 Cookie 仅在请求客户端内存中保存。
- [x] 百度好友、群组发现：读取好友/群组及其分享消息，生成可挂载的关系分享定位信息。
- [x] 百度好友、群组只读空间：目录浏览、原生转存到关联个人空间，并可作为同步来源。
- [x] 分享提取码只存储在分享空间的 `source_ref.passcode`，不会由文件列表接口接收。
- [x] 转存文件由服务端在来源空间重新解析，防止伪造文件 ID、路径和分享令牌。
- [x] 转存成功后清理目标空间根目录缓存。

外部转存当前限制：

- [ ] 前端尚未提供“选择目标个人空间并转存”的按钮和目标空间选择界面；目前可通过 API 调用。
- [ ] 同步目标仅允许同 Provider 的个人空间；个人空间和分享链接可跨账户同步，群组/好友空间仅可同步至关联账户的个人空间。
- [x] 外部转存和同步支持指定目标空间内的子目录。
- [ ] 迅雷尚未实现分享链接空间和外部转存。
- [x] 百度群组空间已实现；其他 Provider 的群组空间尚未实现。
- [ ] 大批量转存仍为同步请求；尚未提供后台任务、进度、重试或取消。

### 我的分享

- [x] 百度、夸克个人空间创建分享链接。
- [x] 百度支持可选四位提取码；夸克由 Provider 返回提取码，不支持指定密码。
- [x] 支持 `0`、`1`、`7`、`30` 天有效期。
- [x] 获取我的分享列表、单条详情和批量取消分享。
- [x] 前端“我的分享”抽屉：刷新、打开、复制详情、取消单条分享。
- [x] 分享链接和提取码不落库，均通过当前账户凭证实时读取。

我的分享当前限制：

- [ ] 前端仅支持逐条取消，未提供多选批量取消。
- [ ] 分享列表目前只展示远端 Provider 已返回的字段，未做本地搜索、筛选、排序或缓存。
- [ ] 百度详情为按分享 ID 从远端列表查找后读取提取码；分享数量较多时需要优化为 Provider 原生详情查询或分页查找。
- [ ] 迅雷不支持创建或管理分享链接。

### 可观测性与安全

- [x] 目录缓存命中、未命中、刷新、失效、锁竞争、读写异常指标。
- [x] 百度、夸克 Provider 请求次数、耗时与结果指标。
- [x] Provider 失败日志只包含方法和固定路径，不记录 Cookie、提取码、分享令牌或请求体。

## 建议顺序

1. 补同步任务进度展示、失败重试和 `cron` 定时调度。
2. 使用好友或群组中的可授权测试文件完成原生转存验证。
3. 完成迅雷真实账号端到端冒烟验证。
4. 为外部分享空间增加前端转存入口和目标空间选择界面。
5. 补文件搜索与文件详情，完善浏览体验。
