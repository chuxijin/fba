# 备考目标：字典配置与接入

## 存储范围

本功能不新增表，仅新增两个非空 JSON 字段（PostgreSQL 使用 JSONB，默认 `{}`）：

- `sys_dict_data.extra`：考试目录与组卷模板；普通字典默认空对象。
- `qbank_v2_user_practice_preference.study_goal`：当前目标及有序已添加列表，空对象表示两者均未设置。多目标继续复用同一 JSONB 列，不新增表或字段。

字典类型编码固定为 `study_exam_target`。每条数据的 `value` 是稳定目标编码（小写字母、数字、下划线，最多32字符），`label` 是显示名称，`remark` 保留为备注。编码不能修改，也不能把已有备考目标移到其他字典类型；变化较大时新增另一编码，停用旧目标。

## 上线顺序

1. 先审查并运行 Alembic 迁移 `a3b4c5d6e7f8`（接 `f2a3b4c5d6e7`），再发布依赖新字段的服务。
2. 迁移只初始化字典类型，不生成考试目录或模板。已有同编码字典类型不会被覆盖。
3. 在管理端「字典管理 → 备考目标 → 字典数据」录入真实目录，在「扩展配置（JSON）」中填写对象。
4. 核实官方规格及对应题池、知识体系、模块ID后再启用模板。可先只配置目录，`templates` 留空。
5. 使用有题库权限的测试账号保存目标、预览模板、开考，验证题数、配额、倒计时、交卷与历史试卷快照。

迁移降级只移除新增字段，不删除运营字典数据；降级会丢失字段内容，应先备份。本文不代表已经执行迁移或部署。

本轮开发环境两列此前已按授权通过 MCP 手工加入，不能直接重复执行同一迁移；多目标扩展仅改变原 JSON 内容，无新 DDL 或数据迁移。本轮未改生产库。

## 配置结构示例

以下仅为结构示例，**不是正式考试目录，不代表任何考试的官方题量或时长**。年度、科目、卷类须按实际业务确认。

```json
{
  "version": "v1",
  "domain_code": "gongkao",
  "region_code": null,
  "exam_kind": "demo",
  "years": [2027],
  "subjects": { "xingce": "行测" },
  "templates": []
}
```

`domain_code` 支持 `gongkao`、`kaoyan`、`cet`、`jiaozhi`；`region_code` 可省略。科目编码与名称由目录统一定义。`years` 为可设置备考目标的年度，最多30个，不代表已经发布该年度招考公告或组卷规格。不同年度模板使用不同 `key` 并填写模板 `years`；如果连科目等目标级规则也发生不兼容变化，再新增稳定目标编码。

## 地区与考试类别

### 统一用户入口与领域联动

首次引导与添加目标共用 `/pkg/practice/study-goal/index` 双栏目录：左侧公务员／研究生，右侧具体目标；点击目标后底部选择类别，仅叶子可进入年度与科目设置。第一层方向只用于目录分组，不再要求用户另外设置“当前领域”。“我的 → 当前备考目标”先打开底部已添加目标列表，点目标快速切换；编辑支持拖动排序和移除，点击完成才保存；底部“添加新目标”再跳详细目录（`mode=add`，不预填当前目标）。首页刷题顶部不再显示重复的目标入口。

- 目标 `extra.domain_code` 是领域关联的配置来源；完整目标优先于旧浏览领域，不从“公考”猜国考、副省类或A类。
- 保存完整目标时，服务端按启用的根分类业务编码 `pc_{domain}`／`kp_{domain}` 查找本环境分类，并在同一偏好更新中关联 `current_category_id`／`current_knowledge_point_id`。不把其他环境资源ID写死在服务端。
- 请求 `browse_domain_code` 表示“只选方向、先逛逛”，清空完整目标并关联浏览目录；这是请求字段，不新增数据库列。不得同时提交非空完整目标。仅浏览没有年度、类别或模板承诺，目标组卷仍要求补全。
- `study_goal: null` 单独提交时只清除当前目标，保留已添加列表及浏览方向；省略仍保留原目标。旧客户端若只切到与完整目标冲突的领域，服务端拒绝并提示通过目标入口切换。
- PostgreSQL 偏好写入按账号加事务锁，防止不同入口并发更新后目标与领域分离。读取历史目标时返回关联的领域；旧类别缺省或目标停用不阻断读取，也不自动换成其他目标。
- 首页及用户中心依据目标更新本地领域与本人偏好缓存，目标变化通知首页刷新。普通刷题不额外按目标地区锁定，目标组卷继续严格匹配年度、类别及科目；历史试卷、会员领域边界、每日演练和高频易错不变。

游客通过 `GET /api/v1/qbank-v2/exam-target-catalog` 读取公开启用目录，响应清空 `templates`，不公开题池ID、知识体系ID及模块资源。完整目录 `/exam-targets`、偏好读写及 `/goal-exams` 仍需登录；JWT免鉴权只精确放行公开目录路径。游客完整目标或仅浏览方向存入独立 `guest` 偏好，登录不自动迁入账号或覆盖云端目标；账号切换后的迟到响应不得写入设置、缓存或导航。

用户中心展示完整“年度 · 目标 · 类别路径”；只选方向展示“待完善”，旧目标缺类别展示“待补选类别”，不能把浏览方向伪装成已完成的正式备考目标。

### 多目标 JSON 与整理契约

数据库新写入格式为 `{"current": goal 或 null, "saved": [goal, ...], "version": 1}`；两者均为空时仍存 `{}`。兼容读取旧扁平目标，将其视作当前且唯一的已添加项；不需要迁移已有行。响应仍通过 `study_goal` 返回当前目标，另返回 `saved_study_goals` 有序列表和 `study_goals_revision` 原状态的 SHA-256 指纹，不把内部封装直接交给旧客户端。

- 已添加项按 `(exam_target_code, exam_year, category_code)` 唯一，最多20个；完整目标保存自动追加或更新同键项，既有顺序不变。同一时间只有一个当前目标，组卷与知识体系默认领域只读取 `current`，不从 `saved` 猜当前。
- 整理请求只提交 `saved_study_goals` 与原 `study_goals_revision`，允许原内容排序／删除，禁止借此新增或修改。指纹不一致拒绝保存，避免覆盖其他设备修改；首次空偏好也返回稳定空状态指纹。
- 已停用、旧类别缺省的目标仍可展示、整理或删除，重新启用和保存必须重新校验有效目录与叶子类别。删除当前项清空当前，保留浏览方向，不自动启用其他项；删除非当前项不影响当前。
- 清当前、“先逛逛”及旧客户端单目标写入都保留已添加列表。整理过程中取消／关闭不落盘，失败保留草稿并提示重新读取。游客目标和列表仍在独立 `guest` 命名空间，本机整理核对原状态，登录不迁入账号。

国考仍是一个目标，地方公务员按地区配置；每个目标的 `categories` 是可选的考试类别树。不按“市考／联考／单独省考”拆成互斥目标：联考是年度、批次属性，不能把多个省份合并成同一个题池。

```json
{
  "categories": [
    { "code": "subprovincial", "name": "副省类" },
    { "code": "prefecture", "name": "地市类" },
    { "code": "law_enforcement", "name": "行政执法类" },
    { "code": "police", "name": "公安类" }
  ]
}
```

以上片段合并进目标 `extra`，不是完整配置。节点仅有 `code`、`name`、`children`；`children` 可省略。每个目标内所有节点编码唯一（小写字母、数字、下划线，最多32字符），最多5层、200个节点，只有末级可选。支持“新疆 → 区考／兵团 → 具体类别”等不同深度；同名A类在不同地区不是同一引用。改名可保留编码，含义变化应新增编码，不能偷偷重定义已有目标。

当前只接入笔试，阶段不提供一个无实际能力的空选择器。类别表示备考方向，例如公安类，不应直接当作一套固定公共科目卷；专业科目需另行配置真实科目和模板。

用户 `study_goal.category_code` 保存所选末级编码（完整父路径由服务端查找）。有类别树的目标必须选择叶子，无类别树只能省略或传 `null`。旧偏好可以正常读取，但保存或新开考前要补选，绝不默认选A类或副省类。考研仍是一个统一目标，本轮不预置院校／专业分类；参照数据未返回的西藏不虚构卷类。

例如国考地市类目标可保存为：

```json
{
  "study_goal": {
    "exam_target_code": "gwy_national",
    "exam_year": 2027,
    "category_code": "prefecture",
    "subjects": ["xingce"],
    "target_scores": {}
  }
}
```

`backend/scripts/seed/study_exam_categories.json` 保存本轮参照的分类名称、层级及本地编码分组，不含Cookie、第三方ID。分类参照不等于正式年度考试规格。广州、深圳可作为备考分类保留，类别可选与年度组卷可用是两个独立状态；历史真题不删除、不跨地区合并。该文件本身不会自动写库，开发库按授权通过 MCP 更新，生产库不自动同步。

本轮开发库目录共35个目标，33个目标配置了120个类别节点（118个末级），其余为考研和未配置卷类的西藏。新疆目标名称调整为“新疆”，内部区分区考与兵团，避免显示“新疆区考 → 兵团”。年度保留2027、2028，所有正式组卷模板仍为空。此为开发库录入记录，不代表生产库已同步或服务已部署。

模板对象字段：

| 字段 | 说明 |
| --- | --- |
| `key` / `name` | 目标内唯一模板编码 / 显示名称 |
| `subject` / `subject_name` | 必须与目录 `subjects` 的编码、名称一致 |
| `category_code` | 有类别树时必须绑定本目标的末级编码；无类别树只能省略或为 `null`，不能拿无类别通用卷兜底 |
| `years` | 非空时仅适用这些年度，不得重复且必须包含在目标年度中；省略或空列表沿用目标年度 |
| `bank_id` | 已发布、启用的公共题库，显式限定出题范围 |
| `knowledge_system_id` | 启用的知识体系，其领域分类须为 `product_catalog` 下的 `pc_{domain_code}` |
| `total` | 总题数，1–500 |
| `duration_minutes` | 考试时长，1–600分钟 |
| `modules` | 1–30个模块，每项包含 `knowledge_point_id`、`name`、`count` |

模块ID须属于该知识体系，包含子知识点；模块ID不能重复，各模块题量之和必须等于 `total`。模块范围交叉时同题仍只投递一次，重叠导致题量不足会报错，不静默补题。每目录最多20个科目、30个模板，配置不接受未知字段。

管理端编辑 JSON 时，雪花ID等超过 JavaScript 安全整数范围的资源ID应使用带引号的十进制字符串；服务端会校验并转换成整数，避免浏览器解析 JSON 数字时丢失精度。不要对ID取整或缩写。

开考沿用题库权益和试看规则，最终可用题量不足时拒绝创建，不会为了凑数放宽题池、权益或模块限制。修改配置会改变 SHA-256 `config_revision`，已打开的模板页面须刷新后再开考。

## API 与小程序

- `GET /api/v1/qbank-v2/exam-targets`：登录后读取有效字典目录，支持可选 `domain_code`。停用、已删除目标及无效类型下数据不返回；错误配置明确报错。
- `GET /api/v1/qbank-v2/preferences`：`study_goal` 返回当前目标，未设置时为 `null`；同时返回 `saved_study_goals` 与 `study_goals_revision`。
- `PUT /api/v1/qbank-v2/preferences`：省略 `study_goal` 保持原值，显式 `null` 清当前但保留列表；完整目标自动 upsert 已添加列表。整理列表必须带原指纹。
- `POST /api/v1/qbank-v2/goal-exams`：仅接受 `exam_target_code`、`exam_year`、`category_code`、`template_key`、`config_revision`、`session_key`，不接受客户端指定配额、题池、时长或用户ID。`category_code` 与本人当前目标必须一致；无类别旧目标可以省略。

目标例子：

```json
{
  "study_goal": {
    "exam_target_code": "demo_target",
    "exam_year": 2027,
    "subjects": ["xingce"],
    "target_scores": { "xingce": 75 }
  }
}
```

目标成绩为选填的0–1000有限数值；使用 Decimal，JSON响应可能为字符串，客户端须兼容。此范围是输入安全限制，不代表任意科目的满分。

服务端从登录用户偏好读取目标，核对年度、末级类别、科目和配置指纹，生成固定 `exam` 模式试卷。模板必须同时匹配年度、类别与已选科目，分类可选但无模板时允许保存目标、拒绝开考，不跨类别或年度兜底。`goal_` 会话前缀保留给目标组卷入口，同参数失败重试沿用同一键；类别变动也属于不同请求。已创建会话重试读取原快照，不因目录停用或偏好改变而重新组卷；旧请求中缺省的类别仅按 `null` 兼容。

已有 `source_snapshot.study_goal` 保存请求、目标、模板和目标名称，新增 `category_path` 保存类别路径每一层的编码和名称；题目沿用原会话快照。后台更新配置不重写历史试卷。已支持保留多个目标，但不增加历史目标审计、考试日期或官方规格自动抓取。

小程序入口：「我的 → 当前备考目标」底部列表；智能组卷进入目标模板预览页，缺目标引导设置，缺模板明确提示。从智能组卷修改目标可预填当前目标，添加入口则使用空草稿。每日演练、高频易错、普通刷题和公考真题入口不受影响。旧 `quick-training?kind=smart_paper` 链接会转到新目标组卷页。
