# 复盘回测：复用现有链路

## 边界

- 复盘保存错因/正确思路，不是成功回忆；无排期时建立次日首次回测。
- 原始独立答错可以作为 Again 证据。首次入错题本采用次日启动，不伪造 Good。
- 后续独立作答由题库专用 FSRS（算法标识含运行时依赖版本、保持率0.9、关闭随机抖动）排期。
- 题库不套用记忆卡默认1/10分钟学习步骤，learning/relearning steps为空，直接由FSRS安排间隔；每天合并提醒而非分钟级刷消息。
- 正确默认Good，错误默认Again。用时不直接映射Hard/Easy；回测提交后可一次确认反馈。
- 错误不能改成Hard/Good/Easy；猜对可把记忆反馈确认成Again，但不篡改客观正误统计。
- 预测回忆率不是考试正确率，原题保持也不代表新题迁移能力。

## 复用与替换

- 不新增消息、任务、练习或记忆状态表。错题状态增加一列fsrs_data，next_practice_time继续是队列唯一到期时间。
- practice_schedule_service替换旧阶梯计算；practice_level仅保留历史兼容，不再参与调度。
- sys_message.payload保存已复盘到期题的完整题目ID、总量、截止时间和当前会话指针；第一次点击才创建现有QbPracticeSession。
- 确定性session_key与现有用户锁保证重复点击、网络重试续接同卷；跨日优先续接未完成回测。
- 不推送原复盘全文，不在发送消息时提前创建空练习记录。
- 未打开/未作答/未判分不记作成功；未完成不清空due。
- 待AI判分题不重复入队；只有已暂停、删除、失效或已提交题的旧卷不阻塞其他到期题。
- resolved仅表示移出错题本，仍参加回测。suspended/deleted停止；关闭提醒只停消息，不清除记忆状态。

## 作答事实与并发

- 复用attempt.grading_result._memory记录算法、before/after、评分、到期时间和确认状态，无额外日志表。
- 已有_projection凭据确保重试/延迟AI判分不重复累计；合并时保留_memory。
- 同会话attempt_no>1不再推进记忆，避免看答案后的改答冒充独立回忆；背题viewed提交同样跳过。
- 延迟判分的submitted_time早于最近记忆时间时不倒退排期。
- 反馈从该次作答before状态重算，不把一次回测算成两次；仅最新有效attempt可确认。
- 用户→会话→题目→错题状态锁顺序沿用现有练习写入顺序。

## 消息和入口

- 每5分钟Celery Beat扫描开启提醒且有到期题的用户，keyset分批，逐用户独立事务。
- 按保存的IANA时区和每日提醒时间补发，当地日期+用户幂等；失败下一轮重试。
- 资格必须满足本人review_count>0且到期。仅进入错题/待复盘列表不算已复盘，即使有历史排期也不进入提醒、开卷和未答续接。
- 不设置题量上限、不分批、不提供下一批按钮。50题符合条件就一次投递50题，超过普通练习500题上限时使用仅服务端可构造的回测参数；普通创建接口限制不变。
- review_daily_limit保留数据库/旧客户端兼容但不参与回测，设置页不再展示。用户自己决定做多少，未答不改记忆状态。
- 其他入口在截止后已独立提交的题不再入本次队列，背题viewed不算独立提交；失败题按FSRS未来排期，不在当前提醒内反复刷。
- 旧限量卷和跨日未答卷补入全部合资格到期题，保留已答事实与数据库原位置；已结束旧卷不改写，仍有剩余时从同一消息创建完整剩余卷并幂等续接，无需下一批入口。
- 回测详情与报告共用整卷阅读题序：按章节名（去首尾空白）聚拢，同名章节跨来源合并，章节按首次出现顺序；无章节题归为同一组。可见题从0连续返回position，前端统一显示1到N，答题卡、实际切题和报告保持一致，而不是只合并答题卡标题。
- 判断推理章内按“图推（图形推理）→定义判断→类比推理→逻辑判断”，言语理解（含言语理解与表达）章内按“逻辑填空→片段阅读”。读取会话所属用户错题状态的module_path，缺失时回退item.display_config中的external_practice.module_path或module_path；未知或缺失题型排该章末尾，同类题保留原位置顺序，其他章节仍按原位置排列。
- 整序只作用于返回视图，不UPDATE数据库原位置、不重建item、不修改response/attempt/FSRS；新卷、旧卷及跨日补题均适用。普通练习和考试不整序。同一回测刷新后以当前question_id恢复阅读位置，显式题目跳转优先，题目已移除时回退首道未答题。
- link_url指向现有/pkg/practice/session/index?recallMessageId=...&mode=practice。
- POST /api/v1/qbank-v2/sessions/recall/messages/{message_id}核验本人消息及服务端payload。
- 已在其他入口完成回测、暂停、删除、题目禁用的题在首次打开时排除；无剩余明确提示。
- 已创建的会话继续原进度，完成后仍可查看；隐藏的会话不被旧消息重建。
- 开卷后再暂停/删除的未答题从回测视图移除，提交接口同样拒绝；已提交事实保留用于查看。手动状态变更与作答共用用户锁，避免暂停后被并发作答重新推进。
- 消息已读与回测完成分开，已读不能推进FSRS。
- 回测关闭解析预取、旧result缓存和本地提前判题；服务端单题solution未提交也拒绝。
- 已交卷但未提交的题也不通过整卷解析接口提前泄露答案；回测标识在创建时写入，保留会话键前缀不能由普通创建接口冒用。
- 提交后反馈卡置于选择数据上方，共用section-card；四档红/橙/蓝/绿，四列、窄屏两列；错误时除Again外禁用，不显示“下次回测”说明。普通练习、背题、考试行为保持不变。
- 回测页不显示顶部剩余题量提示，仅保留真正提交待同步的警告。反馈未确认时四档均不预选，后台仍按默认评分排期；确认后仅所选档位保留实心颜色，不追加“已选”回显文字。
- “我的消息”与底部“我的”导航共用未读计数；前台和切页刷新，已读后失效并重新获取；登出或切账号清空并拒绝旧请求回写。
