# 错题趋势

## 接口与页面

- `GET /api/v1/qbank-v2/wrong-questions/trend`，沿用 JWT 身份与当前领域解析。
- `start_date` / `end_date` 为配置时区的自然日，含首尾，最多366天，不允许未来日期。
- 不传开始日期时，`days=7|30` 按服务端日期生成范围。`today` 始终返回今日统计，与历史范围独立。
- 小程序同页顶部双 Tab，默认左侧“错题复盘”，右侧“错题数据报告”，支持点击和横滑；`?mode=report` 兼容入口直达右侧。原有横屏 `/pkg/charts/wrong-review/trend/index` 通过 EventChannel 保留日期和曲线选择，不再新增普通报告页面。
- 两侧独立滚动、按需加载，来回切换保留下钻、日期与曲线选择；返页只刷新可见侧，隐藏侧在下次切入时更新，避免复盘后继续显示旧统计。隐藏图表暂停，图表和日历手势不触发 Tab 横滑。报告仅展示今日三指标和每日趋势，复盘侧保留原操作、错因及知识点近30天看板。
- `days` 使用整数枚举接收 HTTP 查询字符串 `7` / `30`；`/trend` 必须先于 `/{wrong_state_id}` 注册，旧服务缺少此路由时会把 `trend` 误作整数状态编号。

## 统计口径

三个指标均按同一用户、同一自然日、同一稳定题目去重，彼此独立：

1. 错题：现存真实失败作答与外部 `capture` 事件并集；不含背题提交和 `legacy_initial` 补录。
2. 复盘：`event_type=review` 的事件，不把录入或掌握转换计作复盘。
3. 掌握：新 `qbank_v2_wrong_mastery_event` 记录实际达到掌握状态的转换。自动转换关联作答幂等键；手动重复移出不重复记账，暂停已掌握题再移出也不制造新掌握。

统计按当前错题领域归属过滤，包含已掌握与暂停记录，但排除已删除/撤销的错题、题目与事件。重新答错或暂停不清空已记录掌握事实；删除/撤销会使该题退出趋势统计。这是现存错题的历史活动，不是不可撤销的用户审计账。

`null` 表示未知，`0` 表示已知没有事件。旧外部初次入本没有真实记录时，其原始日期的错题合计为未知，后来的再次录入不能把它补成0。掌握历史不从会被清空的 `resolved_time` 回填。
