# 新导入粉笔报告：外部难度参照趋势

## 边界

- 普通导入按同用户「平台＋报告编号」自动识别：首次正常归档，重导仅补缺失统计，无额外模式或按钮，没有后台回填任务或迁移。
- 使用现有会话 `source_snapshot` 与逐题 `display_config.external_practice`，无需新增表。
- `reference_policy=1` 仅在新报告首次创建逐题会话时启用。旧报告重导不启用趋势，不补逐题归档。
- 已有统计值冻结；重导只填null/缺键，真实0不视为缺失。不同版本或人群不混合。
- 重导不改日期、答案、对错、用时、题干、选项、材料、解析或题型，不新增练习记录。逐题须同时匹配原站题号、原卷题序、模块路径、规范化题干/选项、标准答案和材料，否则跳过并提示。
- 仅汇总旧记录可建立绑定原记录的1:1只读元数据会话保存整卷统计，不补造题目、响应或作答；没有整卷统计则不建容器。
- 首次参照分别保存在题项`reference_original`/`reference_backfilled`和会话`reference_original_report`/`reference_report_backfilled`，趋势始终读首次值；重导不能提高原历史覆盖率。
- 删除报告后重新导入按照现有机制是新记录，不保留已删除报告的分析贡献。
- 现有手动、在线趋势与模块对比不变。本接口只分析粉笔同科目、同练习类型的数据。

## 导入

插件被动拦截 `/combine/question/getMeta`，用请求 `requestKey` 与本报告 `getSolution.switchVO.requestKey` 精确匹配，再按 `globalId` 对应逐题。只接受粉笔官方HTTPS接口，不主动重发统计请求，不保存鉴权key到导入参数。

逐题 `platform_reference`：

- `version=fenbi-global-v1`，`population=platform_unspecified`。
- `captured_at` 是首次捕获该响应的时间；缓存重播沿用原响应时间。
- `correct_ratio_percent` 已是0–100百分数；原平台数值不额外乘100。
- `total_count_raw`、`wrong_count_raw`、`most_wrong_choice` 为白名单原值，缺失为null，真实原0保留0。

报告 `platform_reference` 保存 `difficulty_raw`、`average_score`、`beat_rate_percent`、`highest_score`、`sigma_raw`、`total_user_raw`，按subReport.type定位，不依赖数组位置。统计须随逐题提交。

统计时间、人群去重、题目区分度、猜测参数、首次作答口径均未提供。`totalCount` 不视为有效独立样本量；异常 `wrongCount=0` 和 `totalUser=0` 不参与计算。整卷难度方向与量表未知，仅展示原值，不混合本地1–5经验难度。

重导保留原快照`captured_at`，新增字段分别记录实际时间：逐题详情返回`platform_reference_field_captured_at`，整卷同名映射在`source_summary`内。映射中的时间优先于原快照时间，不能把后补值解释为作答当时统计。

`POST /api/v1/gk/practice-logs/import-report` 的重导结果返回 `reference_supplement`（整卷新增字段数、逐题新增字段数、更新题数、跳过题数及最多20条警告），`practice=null`；`enriched`只代表实际补入统计。重复点击无新缺失时不再写入。

服务器为新归档题固定身份指纹（规范化题干/选项、材料和标准答案），不从会被后续编辑的共享题目取版本。不将解析展示变化视为新题版本。

## API

`GET /api/v1/gk/practice-logs/reference-trends`

- JWT鉴权，只查当前用户未删除记录/会话/逐题项。
- `subject_name` 默认行测；`material_type` 为exam/practice/special，默认exam；可选 `module_name` 只筛互斥一级模块，不累加重叠知识点。
- `start_date/end_date` 默认最近90天（服务端北京时间归日），最多366天。
- 最多1000报告、50000逐题项；超过上限返回请求错误，要求缩短区间，不拿截断数据作完整趋势。
- 返回旧报告与未齐全逐题记录的排除数量、连续自然日points、前后窗口comparison、最近报告原始平台总览、算法版本与口径提示。
- 手动修改练习日期仍按现有展示日期归日；冻结平台抓取时间不随之改变。

## 计算

1. 原始正确率：当日全部完整归档作答的正确数/题数，含重复作答，与新参照线的题集区别明确标注。
2. 同日参照：同稳定题号+固定内容指纹只计一次；当日状态、路径、题型冲突的题保守排除，不挑表现最好的一次。跨模块筛选也不隐藏冲突。
3. `p_i=correct_ratio_percent/100`、`y_i=1`（正确）或0（错误/未答）。同题参照差值 `100×mean(y_i-p_i)`，单位**百分点**，不是能力分。
4. 参照覆盖分母为当日独立身份题数（含冲突、缺meta），无身份的项也计入缺失分母；有效覆盖不足80%时日差值为null，不进入滚动线或方向比较。
5. 近7天线按有效题数加权，至少20题、2个活跃自然日；无作答日期为null，不补0、不跨缺口连线、不曲线平滑。
6. 方向比较：后28天截至筛选end_date，前28天紧邻。只有选定观察区间内首次出现的同版本题参与比较；低覆盖日或冲突日首见的题不能通过后续重做重新变成首见。**不能解释为生涯首次作答**；改变观察区间会改变可观测首见集合。
7. 模块×题型×固定正确率分层（低于40%、40%至70%、至少70%）。共同格子前后各至少5题；共同支持在前、后窗各至少覆盖70%。权重取两窗格子占比均值，在共同格子内归一化，前后用同一组权重。
8. 前后窗各至少40道有效首见题、5个活跃自然日。按自然日成簇重采样500次（稳定seed、固定格子权重），有效重采样至少80%；取2.5%/97.5%描述性分位区间。不使用平台原计数进行二项置信区间或线性加权。
9. 区间全大于0/全小于0仅命名为「相对参照提高/下降」；跨0为「方向尚不明确」，不足为「证据不足」。任何方向都不是绝对能力增长或学习策略的因果证明。

质量门槛为保守的产品决策，不是普适统计定理。日期之间仍可能相关，跨时间的全站人群也可能变化；描述性区间不包含这些未知偏差。没有经过校准的Rasch/IRT参数，不取logit冒充能力，不预测上岸概率。

## 小程序

在「练习数据 → 导入/手动记录」下追加参照趋势区，沿用上方日期筛选；模考/练习/专项分开，支持一级模块、参照差值/正确率切换与图例曲线开关。未知断线，真实0保留。Canvas仅在可见、原生布局测量成功后创建；账号、领域、页面隐藏、卸载或请求乱序均使旧响应失效。

当前只提供纵向参照区；既有原始模块对比横屏页保留。无需新增页面路由、主包依赖或构建配置。
