## 纯净版（用户最终看到的）

基层形式主义是指基层工作中重形式轻内容的现象，数字化治理和痕迹管理本为规范流程、提升效能，但若层层加码，就会异化为负担。当前主要表现为：一是"指尖上的形式主义"：APP过多，干部疲于打卡填表，时间被大量消耗；二是"痕迹主义"，迎接检查需准备大量台账材料，重留痕轻实绩，看似规范，实则把精力引向材料应付；三是变通执行，如"无会周"被改名为"碰头会"规避。

其反复滋生，根子在于权责不匹配、层层传导压力、容错纠错不足，考核又过度看重痕迹材料，技术工具和减负政策遂在执行中走样。解决基层形式主义问题，需要转变考核导向，以群众满意度为核心；精简政务APP，避免重复填报；建立反向考核机制，让基层干部对上级部门有评价权。同时要加强监督，严查变通执行行为，确保减负政策真正落地。减负不是减责任，而是让基层干部从材料堆里解放出来，把时间用在走访群众、解决难题上。
