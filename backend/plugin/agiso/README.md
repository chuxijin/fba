# 阿奇索发货工具集成插件

## 功能说明

本插件用于接收阿奇索发货工具的 Webhook 推送，支持以下功能：

1. **统一推送接口**：一个接口接收所有推送类型，自动识别推送类型
2. **支付推送**：接收买家支付完成通知，自动创建订单记录
3. **发卡推送**：接收自动发卡通知，获取卡密并兑换会员权益
4. **签名验证**：验证阿奇索推送签名，确保数据安全
5. **推送日志**：完整记录推送数据，便于追踪和调试
6. **智能识别**：根据推送数据特征自动判断推送类型
   - 包含 `Cards` 字段 → 发卡推送
   - 包含 `Payment` 字段 → 支付推送

## 配置说明

在系统配置中添加以下配置项：

```python
# 阿奇索配置
AGISO_APP_SECRET: str = 'your_app_secret'  # 阿奇索 AppSecret
AGISO_WEBHOOK_URL: str = 'https://your-domain.com/api/v1/agiso/webhooks/payment'  # 推送地址
```

## 推送地址配置

在阿奇索后台配置以下推送地址：

- **统一推送地址**：`https://your-domain.com/api/v1/agiso/webhooks/delivery`

系统会自动识别推送类型并分别处理。

## 使用说明

1. 在阿奇索后台获取 AppSecret
2. 在系统配置中添加 AppSecret
3. 在阿奇索后台配置推送地址
4. 测试推送功能是否正常

## 技术架构

- **签名验证**：使用 MD5 算法验证推送签名
- **幂等性**：基于订单号防止重复处理
- **异步处理**：使用异步函数处理推送数据
- **日志记录**：完整记录推送数据用于审计
