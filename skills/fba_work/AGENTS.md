# 工作资料归档约定

- 进入本目录先阅读README.md索引，只加载当前工作对应的README与WORKFLOW。
- 每种工作一个功能目录；新工作登记到本目录README索引。
- 现行规则只在对应WORKFLOW.md维护，不复制多份完整规范。
- 每次执行创建独立runs/YYYYMMDD-任务名目录，README必须明确“待定位/处理中/已提交并复核”等真实状态。
- 脚本按性质区分：通用工具放scripts，本轮固定参数脚本跟随本轮run归档，旧脚本放archive。
- archive默认不阅读、不执行；历史SQL不能重放。需要历史事实时按索引定向查阅。
- 临时分片、调试日志、预览放run/work，完成且确认不影响追溯后可清理；不要在doc、scratch、仓库根目录新建这类任务产物。
- 源快照、最终成品、复核结果、状态说明、备份信息不得作为临时文件自动清理；不删除不明归属文件。
- 不存储密码、令牌，不连接数据库进行“归档检查”。生产改动必须按对应工作规范另行授权和执行。
